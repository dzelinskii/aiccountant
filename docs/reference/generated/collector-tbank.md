# Коллектор: перевод словарей Т-Банка

Слова банка не покидают его плагина: здесь они переводятся в общий словарь
приложения. Подсказок о категории — 37.

## Группа операции → вид

- `CASH` → `cash`
- `INCOME` → `income`
- `INTERNAL` → `transfer_self`
- `LOANREPAY` → `loan`
- `PAY` → `purchase`
- `TRANSFER` → `transfer_person`

## Подгруппа → вид (уточняет группу)

- `C10` → `transfer_person`
- `C3` → `cash`
- `C4` → `transfer_person`
- `C5` → `transfer_self`
