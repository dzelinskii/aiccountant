# Коллектор операций банка

Ядро сбора и плагины банков — **Т-Банк**, **Сбербанк** и **Альфа-Банк**.
Отдельно не запускается: работает в окне десктопного приложения (`desktop/`),
куда его импортирует фронт (`frontend/src/desktop/collector-host.ts`). Забирает
операции из личного кабинета банка и отправляет их в AIccountant готовым
импортом — его остаётся подтвердить в приложении.

Коллектор отвечает за то, что спросить у банка и как перевести ответ в словарь
приложения. Всё, что касается машины и сети, делает оболочка
(`desktop/src-tauri/`): окно входа в банк, хранилище секретов ОС, доставку
запросов к банку, список разрешённых адресов и доверие к УЦ Минцифры.

Что коллектор гарантирует и чего не делает — в
[docs/reference/collector.md](../docs/reference/collector.md).

## Устройство

- `src/app.ts` — единственный вход для приложения: всё, что нужно фронту.
- `src/collect/` — сбор одного банка: сессия, привязка счетов, отправка
  импорта, итоги.
- `src/plugins/<банк>/` — плагин банка: вход (`login.ts`), клиент и пути ручек
  (`client.ts`), разбор ответов (`index.ts`), перевод словарей банка (`map.ts`).
- `src/plugins/registry.ts` — список банков.
- `src/http/` — клиент банка (`bank-client.ts`) и интерфейс транспорта
  (`transport.ts`); транспорт для приложения даёт оболочка
  (`frontend/src/desktop/bank-transport.ts`).
- `src/core/` — общее для всех банков: контракт плагина (`contract.ts`),
  подсказки категорий и коды MCC (`category-hints.ts`), суммы (`money.ts`).

## Как добавить банк

1. Плагин в `src/plugins/<код>/`, реализующий `BankPlugin` из
   `src/core/contract.ts`. Код банка — строчные латинские буквы, цифры и
   подчёркивание: из него собирается поле `parser` импорта (`<код>_collector`).
2. Строка в `src/plugins/registry.ts`.
3. Банк в оболочке — `desktop/src-tauri/src/banks.rs`: хост API, домен окна
   входа, пары «метод, путь» всех ручек плагина и доверие к УЦ. Запрос по
   адресу вне этого списка оболочка отвергает; сверку списка с ручками плагина
   в обе стороны делает `src/plugins/shell-allowlist.test.ts`.
4. Таблицы перевода — в генератор справочника `scripts/gen-reference.ts`: сами
   они в `docs/reference/generated/` не появятся.
5. Банк в приложении — `backend/app/core/banks.py`: экран «Банки» берёт список
   из `/api/banks`, и без записи там банка на экране не будет, а приложение
   отвергнет его код. Подпись источника импорта — в
   `frontend/src/pages/ImportPage.tsx`.

## Разработка

    pnpm install
    pnpm test        # vitest; ответы банков — фикстуры Т-Банка в tests/fixtures/, у Сбера и Альфы данные в самих тестах
    pnpm lint        # oxlint --deny-warnings
    pnpm build       # проверка типов, tsc --noEmit
    pnpm reference   # перегенерация docs/reference/generated/collector-*.md

Тесты в сеть не ходят. Вход в банк требует человека и проверяется только живым
запуском приложения.

`pnpm reference` пишет таблицы перевода словарей в справочник; CI сверяет их с
закоммиченными, поэтому после правки `map.ts` генерацию надо прогнать и
закоммитить.

## Уборка за прежним запуском из командной строки

Раньше коллектор запускался отдельно, из командной строки, и хранил доступ к
банкам сам. Приложение эти места не читает и не стирает, поэтому у тех, кто
тем запуском пользовался, остались секреты банков — их надо убрать руками:

- **Хранилище секретов ОС**, служба `aiccountant-collector`, по записи на банк
  (`tbank`, `sber`, `alfa`). Windows: найти записи —
  `cmdkey /list | findstr aiccountant-collector`, удалить каждую —
  `cmdkey /delete:<имя из списка>` (или в «Диспетчере учётных данных», раздел
  «Учётные данные Windows»). macOS: `security delete-generic-password -s
  aiccountant-collector -a <банк>` для каждого банка (или в «Связке ключей»).
- **Профили браузера с куками банков**: каталог `collector/profile/` — в каждой
  копии репозитория, откуда запускали, — либо подкаталоги `tbank`, `sber`,
  `alfa` в `$COLLECTOR_PROFILE_DIR`, если он был задан. Удалить целиком.
