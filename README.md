# AIccountant

AI-помощник по личным финансам: чтение финансовых документов (выписки,
чеки, квитанции), сверка с транзакциями, аномалии, прогноз расходов.

Дизайн и дорожная карта: [спека](docs/superpowers/specs/2026-07-02-aiccountant-design.md).

## Что реализовано

- **Этап 1.1 — identity.** Регистрация/вход (argon2, сессии в Redis, CSRF),
  workspace, роли, приглашения участников.
- **Этап 1.2a — ядро учёта (ledger).** Счета (карта/наличные/накопления,
  архивация), категории-дерево с дефолтным набором, транзакции (расход/доход
  со знаковой суммой, переводы парой атомарно), лента с фильтрами и
  пагинацией, дашборд (остатки, расходы месяца по категориям, последние
  операции). Данные строго изолированы по `workspace_id`; границы модулей
  контролирует import-linter. Деньги — `NUMERIC(20,4)`/`Decimal`, на клиент
  передаются строками.

- **Виды операций.** Не всякое движение денег — трата: перевод между своими
  счетами или снятие наличных деньги не тратят, а перекладывают. Вид операции
  определяет коннектор банка и переводит его в общий для приложения словарь —
  слова конкретного банка в ядро не попадают. Переводы между своими счетами и
  операции с наличными в статистику расходов не входят и не категоризируются;
  любую операцию можно вручную вынести из статистики или вернуть в неё.
  Правила «описание → категория» позволяют раскладывать повторяющихся
  контрагентов автоматически.

  Не всякий приход — доход. Банк присылает одну и ту же пометку и на перевод от
  человека, и на перекладывание денег между вашими же счетами, и на внесение
  наличных: различает их подгруппа операции, и мы её разбираем. Про деньги от
  человека честно сказать только это — «пришли от человека»: возврат долга,
  подарок и оплата работы выглядят одинаково, и выбирать за вас мы не будем.

- **Категории запоминаются.** Подтвердили категорию у операции — система
  запомнила правило, и такие же операции дальше раскладываются сами, **не
  обращаясь к языковой модели**. Правило, заведённое вручную, подтверждением не
  перезаписывается. Если операции с тем же описанием уже лежат без категории,
  приложение спросит, разложить ли их; трогает оно при этом только те, у которых
  категории нет вовсе — ни ваши решения, ни машинные не переписываются.

- **Категорию подсказывает банк.** Банк уже знает, на что потрачены деньги, —
  мы принимаем его подсказку и переводим в свои слова: справочник банка на 90
  значений сжимается в 37 подсказок приложения, так что «Duty Free» и «Металлы
  в слитках» в дереве категорий не заводятся. Где своей метки у банка нет,
  работает MCC — международный код торговой точки, одинаковый во всех банках.
  Подкатегория создаётся при первой же операции с такой подсказкой, поэтому
  дерево пополняется только тем, на что вы действительно тратите. Порядок
  такой: ваше решение сильнее подсказки банка, подсказка банка сильнее догадки
  языковой модели — **и всё это работает без ключа к модели вообще**. Итоги на
  дашборде считаются по верхнему уровню категорий, детализация видна в ленте.

- **Остаток по счёту.** Остаток берётся у того, кто его сообщил: для счетов под
  коллектором это банк, и рядом видно, на какой момент число верно. Счета,
  которые никто не собирает, — наличные, банк без коллектора — правятся руками:
  человек задаёт текущий остаток, дальше тот сам движется вслед за операциями.
  Счёт опознаётся по последним цифрам карты, а если карт нет — по своему типу.

Демо: _URL появится, когда проектом можно будет хотя бы частично удобно
пользоваться. Деплой не привязан к этапам._

## Структура

- `backend/` — FastAPI, модульный монолит (Python 3.12, uv)
- `frontend/` — React 19 + TypeScript + Vite (pnpm), PWA
- `collector/` — сбор операций из личного кабинета банка (Node + TypeScript):
  Т-Банк и Сбербанк, запускается на машине пользователя, см.
  [collector/README.md](collector/README.md)
- `infra/` — docker-compose, Caddy, деплой

## Запуск локально

    cp .env.example .env
    docker compose up --build

Приложение: https://localhost, API: https://localhost/api/health
(для localhost Caddy выпускает самоподписанный сертификат — браузер
предупредит, для curl нужен флаг `-k`).

## Разработка без Docker

    cd backend && uv run uvicorn app.main:app --reload    # API на :8000
    cd frontend && pnpm dev                                # Vite-прокси /api → :8000
